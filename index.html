Game Topic Radar — Demo

Read-only demo of how this tool uses the YouTube Data API: it searches public videos about a game and ranks them by view count (real audience attention). It only reads public metadata — it never posts, comments, votes, or accesses any private user data.

Sign in (demo account)
Search a game

Each result is a public YouTube video, fetched live via youtube/v3/search + youtube/v3/videos (read-only), ordered by view count. High view count = a topic real audiences watch. The API key is stored server-side only and is never exposed to the browser.

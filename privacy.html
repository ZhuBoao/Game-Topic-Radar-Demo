Privacy Policy — Game Topic Radar

Last updated: 2026-06-24

Game Topic Radar is a personal, non-commercial research tool operated by a single individual to discover video-game history and trivia topics for content planning. This page also covers the hosted read-only demo at this site.

No end-user data

The tool and demo have no end users other than the operator and authorized reviewers. There is no Google sign-in. The demo uses a single shared demo login only to gate access for review. We do not collect, store, or process the personal data of any third party, and we set no tracking cookies (only a short-lived session cookie for the demo login).

Use of YouTube API Services

The tool and demo use YouTube API Services to search and read publicly available video metadata (titles, view counts, channel names, publish dates) about specific video games. They read public data only — they never post, comment, vote, rate, modify, or delete anything on YouTube, and never access private user data. Use of YouTube API Services is subject to the YouTube Terms of Service and the Google Privacy Policy.

Storage & retention

Retrieved public metadata is cached temporarily and locally on the operator's own machine, solely for topic research. Nothing is shared, sold, redistributed, or used to train machine-learning models. Cached metadata is short-lived and may be deleted at any time. The YouTube API key is stored only as a server-side environment variable and is never exposed to browsers.
